# Field dictionary

All extracts live in `data/tableau/` and are regenerated by `python -m retailpulse`. Money is in USD as recorded in the source.

## `sales_wide.csv`: the main data source (one row per order line, 10,192 rows)

| Field | Type | Definition |
|---|---|---|
| `row_id` | integer | Source Row ID; primary key of `mart.fct_sales` |
| `order_id` | string | Order identifier; one order has one or more lines |
| `order_date` | date | Date the order was placed |
| `ship_date` | date | Date the order shipped |
| `days_to_ship` | integer | `ship_date - order_date` |
| `ship_mode` | string | Standard Class, Second Class, First Class, Same Day |
| `customer_id` | string | Customer identifier (foreign key to `mart.dim_customer`) |
| `customer_name` | string | Customer name as recorded (synthetic) |
| `segment` | string | Consumer, Corporate, Home Office |
| `country` | string | United States or Canada |
| `region` | string | Central, East, South, West |
| `state` | string | State or province |
| `city` | string | City |
| `postal_code` | string | ZIP or postal code (text, so leading zeros and Canadian codes survive) |
| `regional_manager` | string | Manager of the region (from the source `People` sheet) |
| `product_id` | string | Source product ID. **Not unique to one product:** 32 IDs carry two names, so products are keyed on (`product_id`, `product_name`) |
| `product_name` | string | Product name |
| `category` | string | Furniture, Office Supplies, Technology |
| `sub_category` | string | 17 sub-categories |
| `quantity` | integer | Units on the line |
| `discount` | real | Discount rate on the line (0 to 0.8) |
| `gross_sales` | real | List-price value of the line: `sales / (1 - discount)` (derived) |
| `discount_amount` | real | `gross_sales - sales` (derived) |
| `sales` | real | Net revenue on the line, after discount (recorded) |
| `profit` | real | Profit on the line (recorded) |
| `implied_cost` | real | `sales - profit` (derived from the two recorded fields; the source has no independent cost) |
| `is_returned` | boolean | Order appears on the source `Returns` sheet |

| `discount_bands.csv` | discount band | Dashboard 3 |
| `margin_bridge.csv` | sub-category × year | Dashboard 3 (mix vs rate effect) |
| `customer_rfm.csv` | customer | Dashboard 4 |

| `segment_summary.csv` | segment × year | Dashboard 4 |
